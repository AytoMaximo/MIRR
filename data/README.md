
# data/README.md — куда положить реальные логи

Папка `data/` предназначена для ваших реальных журналов из Unity/ARFoundation.

1) Скопируйте сюда файл `attempts.csv` (или несколько файлов) по схеме из `src/io_schema.md` (раздел "Журнал попыток восстановления").

2) (Опционально) добавьте `nodes.csv` для метрик уровня навигации (узлы выбора).

3) Затем отредактируйте `src/run_all.py`:
- замените `DEMO_LOG` на путь к вашему `attempts.csv`,
- при наличии узлов — замените `DEMO_NODES` на путь к вашему `nodes.csv`.

Важные замечания к воспроизводимости:
- фиксируйте версию приложения и сборки платформы (ARCore/ARKit), модель устройства;
- логируйте `ver(i)` для якорей и версию навигационной карты, если вы используете обновления;
- храните конфиг порогов (τ_min, Δτ_min, τ_conf, Δτ_conf), Time, α_route и n_eff рядом с экспериментом.
